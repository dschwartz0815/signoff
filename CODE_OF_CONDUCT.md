# Code of Conduct

This project adopts the [**Contributor Covenant v2.1**](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) verbatim. The full text is maintained at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>;
we reference it by link rather than copying it in-tree so any
future erratum or clarification the Covenant maintainers publish
applies here without a repo update.

By participating in this project — filing issues, opening pull
requests, commenting in discussions, or interacting in any other
community space tied to this repository — you agree to abide by
the Covenant.

## Enforcement contact

Reports of behaviour that violate the Covenant go to
**`conduct@signoff.dev`**. Reports are handled privately.
Response time target: **2 business days** to acknowledge,
**7 business days** to describe next steps. All reports are
treated as confidential; retaliation against a good-faith
reporter is itself a violation.

For security vulnerabilities (as distinct from conduct issues),
see [`SECURITY.md`](./SECURITY.md).
